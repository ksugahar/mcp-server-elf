# ELF/MAGIC Source-Native Loop Policy

ELF/MAGIC public MCP loop slots should start from public-safe ELF-native
material: bundled help topics, public sample decks, recipes, Python facade
contracts, and publication-safe deck families.

Generated snippets are allowed as replay harnesses, lints, public reduced
analogues, or negative controls. They are not the source-native lesson seed.

For each loop artifact or public sample-deck promotion, record:

- `source_native_example`
- `source_native_type`
- deck family or documentation topic
- requested observable contract
- public validation level
- run date, package version, and compact timing stages when an executed result
  is involved
- `learning_lanes.public` and `learning_lanes.source_tool`

The public package must not include licensed solver output, internal file
paths, private cross-validation logs, or commercial benchmark values. Public
learning is limited to reusable deck structure, observable contracts, parser
shape, documentation knowledge, and open validation candidates.

The preferred public source-native seeds are representative sample decks,
motor-readiness routes, public validation matrices, and numeric invariant deck
families. Product/private solver replay remains outside this public MCP
package.
